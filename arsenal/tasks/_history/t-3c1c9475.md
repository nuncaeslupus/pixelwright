`--dry-run` is documented as "show the request hash and estimated cost; send
nothing", but the key check runs before the dry-run short-circuit:

```
$ pw generate hill --provider pixellab --dry-run --json
{"ok": false, "command": "generate", "error": {"code": "missing_key",
 "message": "no API key for pixellab: set PW_PIXELLAB_KEY or add `pixellab = \"...\"` under [keys] in .pixelwright/secrets.toml"}}
```

Same for gemini, gpt-image and retro-diffusion. So nobody can preview what a
provider would cost before signing up for it — which is the main reason to run
a dry run. Measured 2026-11-15.

Decision: move the key lookup after the dry-run branch. A dry run needs the
provider's price table and the request hash, neither of which needs a key.
