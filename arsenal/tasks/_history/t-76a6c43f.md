For images reduced to the canvas (no pixel grid): edge-preserving simplification (Kuwahara or mean-shift) before reducing, then removal of small same-colour clusters (2-4 px, not only single orphans) that carry no shape. Accents from `core/importance` are protected. Evaluate region-based abstraction (Gerstner et al., *Pixelated Image Abstraction*) and keep it if it reads better on the test painting.

## Acceptance gate
Gate metric (from the plan): `stray_cluster_share <= 0.02`.

```bash
make check
uv run pytest tests/core/test_abstract.py -q
```
