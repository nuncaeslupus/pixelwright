An asset whose canvas is 160x90, generated at 640x360 through ComfyUI with the
pixel-art LoRA: the painter laid down 8-pixel blocks, so `pw snap` detected
scale 8 (confidence 0.979) and wrote an 80x45 image — half the declared canvas
— with no warning. Every later stage then worked happily at the wrong size.

```
{"ok": true, "command": "snap", "version": "v0003",
 "data": {"scale": 8, "offset": [0, 0], "confidence": 0.979...}}
```

Measured 2026-11-15. snap trusting the detected grid is right; staying silent
about the mismatch is not.

Decision: keep the detected grid, add a warning when the snapped dimensions
differ from the asset canvas, naming both sizes and the detected scale. No
resizing, no error — the painter's grid is evidence about the image, and the
decision stays with the user.
