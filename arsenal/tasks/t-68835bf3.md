`snap` detects and resamples non-integer pixel sizes (e.g. 2752 px / 320 = 8.6), so the grid does not drift across the image and dither checkerboards and diagonals survive. Integer scales keep today's behaviour.

## Acceptance gate
Gate metric (from the plan): `grid_drift_px <= 0.5`.

```bash
make check
uv run pytest tests/core/test_snap.py -q
```

## Tests
`test_snap_recovers_non_integer_scale` in `tests/core/test_snap.py`: native art with a checkerboard and a 1:1 diagonal, upscaled by 8.6 with bilinear blur, snaps back to its native size with >= 95% of pixels matching
