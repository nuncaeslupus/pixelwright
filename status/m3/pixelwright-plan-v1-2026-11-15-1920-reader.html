▸Technical solution

▸Architecture overview

M3 adds a painter in front of the M1-M2 pipeline and a guide around it:

  • Providers (src/pixelwright/core/providers/): the Provider protocol, GenRequest, GenResult, Capabilities and Cost from the main spec §5; a registry by name; a request hasher (canonical JSON plus SHA-256 of every input image); a file cache in the workspace cache/; retry 2x with backoff on 429/5xx; a budget guard and a cost ledger. Adapters are one module each: replay, comfyui, gemini, retro_diffusion, pixellab, gpt_image. HTTP goes through one small client (urllib, injectable transport) so tests replay recorded responses and never touch the network.
  • Generation commands (cli/, mcp/): generate and regen-region write candidate versions through the existing Asset API, reading the style guide's generation preset for the provider. cost, doctor and next are read-only.
  • Guided first run: pw tour builds a workspace in a temp or given folder from a bundled sample drawn by code (fixtures/tour.py), runs every step with the replay provider, prints a short "what happened / why / look at" block per step, and ends by opening the viewer. pw next <id> and the viewer hint share one function (workspace/next_step.py) that maps an asset's state to the next action.
  • Benchmark (src/pixelwright/bench/): a run matrix (providers x chains x briefs x samples) with a cost estimate shown before anything is sent, detector scores from the check catalog, a Claude pairwise file Claude fills through MCP, a blind pairwise page in the viewer for the artist, Bradley-Terry ranking, and report.html.

▸Data flow

pw generate bg01 --provider comfyui --mode img2img --n 2
  -> style preset (style.yaml generation.comfyui) + asset sketch + palette
  -> GenRequest -> hash -> cache hit? -> GenResult (cost 0, logged)
                        -> miss: budget guard -> adapter.generate -> cache write -> ledger
  -> one version per image (stage draft, or experiment with --experiment),
     meta.yaml: provider, model, mode, request_hash, seed, cost_usd, cache_hit, licence
  -> envelope {"ok": true, "data": {"versions": ["v0007", "v0008"], "cost_usd": 0.0}}

▸Contracts

GenRequest (frozen dataclass): mode (txt2img|img2img|edit|inpaint), prompt, negative, init_image (path or None), mask (path or None), references (paths), palette (list of hex or None), size (w, h), seed (int or None), n (1-4), params (dict). Hash = SHA-256 of canonical JSON with image paths replaced by their SHA-256.

Errors (envelope from main spec §5): provider_unavailable (exit 5, e.g. ComfyUI not running, with the fix in message), provider_error (exit 5, after retries), capability_missing (exit 2, e.g. inpaint on Gemini), missing_key (exit 2, names the env var and the secrets file), budget_exceeded (exit 6, with spent, limit and estimate).

CLI (all with --json):

Command Result data
pw generate <id> --provider --mode [--prompt/--prompt-file] [--n] [--seed] [--experiment] [--dry-run] versions, cost_usd, cache_hits; --dry-run: request_hash, estimate_usd
pw regen-region <id> --issue <n> --provider [--version] version, pixels_changed, issue
pw cost [--month] [--by provider\|asset] spent_usd, limit_usd, rows
pw doctor one row per check: Python, Aseprite, each provider (key present, reachable), budget, ComfyUI models
pw next <id> step, command, why
pw tour [--path] [--no-view] workspace, steps
pw bench run --matrix <file> [--yes], pw bench rank, pw bench report run ids, estimate; ranking; report path

MCP: generate, regen_region, cost_report, next_step, bench_*, from the same registry (M2 pattern).

▸Technology choices

Choice Justification
stdlib urllib with an injectable transport No new HTTP dependency; recorded-response tests are trivial
ComfyUI HTTP API (/prompt, /history, /view) with workflow JSON per preset in package data Main spec contract; presets are editable files, not code
Bradley-Terry by MM iteration in numpy ~20 lines; no stats dependency
Sample art drawn by code D-M3-4: no third-party images; deterministic

▸Out of scope

Style LoRA training, animate mode, scene preview and light zones, rigs, generation from the viewer (D-M3-5), any provider without a licence note.

▸Task details

  • T34 Framework: protocol, dataclasses, registry, hasher, cache, retry/backoff, transport injection, errors; a fake provider for tests only.
  • T35 Cost control: [budget] and secrets loading, guard before every non-cached call (estimate + spent this month > limit → exit 6), cost.jsonl, pw cost, .gitignore entries for cache/, .pixelwright/secrets.toml.
  • T36 Replay and sample: replay serves images from a folder keyed by request hash or in order; fixtures/tour.py draws a small sketch (lines) and a "painted" version (soft gradients and noise) at 4x of a 160x90 canvas, so snap and quantize have work to do.
  • T37 generate: modes txt2img/img2img/edit/inpaint per capability, style preset merge (preamble + prompt, references, palette as input or swatch image), --n candidates, --experiment stage, --dry-run; MCP tool.
  • T38 Next step: states (no source, sketch only, raw generated, snapped, quantized, cleaned, checks failing, open issues, ready to approve, approved, exported) → command and one-line why; pw next; the viewer shows it in the empty side panel and status bar.
  • T39 doctor: table output plus --json; each failing row says how to fix it.
  • T40 tour: steps with a "what happened / why / look at" block each; --path keeps the workspace; opens pw view at the end unless --no-view.
  • T41 Guide: docs/guide/how-it-works.md (one drawspec diagram of the loop, glossary, "your first real asset"); README and pw --help link it; plugin skill first-run.
  • T42 ComfyUI: queue a workflow, poll history, fetch images; txt2img, img2img, inpaint; clear provider_unavailable when the server is down; recorded responses in tests.
  • T43 regen-region: build an inpaint request from the issue mask (box or PNG), paste the result only inside the mask, resolve the issue with the new version.
  • T44 Candidates: Compare offers siblings sharing a request hash; pick one, reject the rest.
  • T45 Setup: install guide (ComfyUI, models, a pixel-art LoRA with a licence note), presets for Flux and SDXL, and status/m3/local-comfyui-test-prompt.md for the owner's local session.
  • T46-T49 Paid adapters: each from the provider's current API docs at implementation time; capability flags, price per image, licence note, recorded responses with keys stripped. Real calls only in the owner's local session.
  • T50 Bench run: matrix.yaml (main spec: 3 generators x 2 chains x 3 briefs x 3 samples), estimate, --yes to spend, resumable, detector scores per output.
  • T51 Ranking: Claude pairwise through MCP (bench_pairs_next, bench_pair_record), blind pairwise page in the viewer, Bradley-Terry, report.html, pw bench apply writes [defaults].
